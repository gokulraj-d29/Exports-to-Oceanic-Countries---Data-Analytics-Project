# 🌏 Exports to Oceanic Countries - Data Analytics Project

## 📌 Overview
This project analyzes **India’s exports to Oceanic countries** using Python.  
It covers **data cleaning, exploratory data analysis (EDA), visualizations, and insights** to understand trade dynamics, commodity trends, and currency impacts.

## 🚀 Project Workflow
1. **Data Loading** → Import dataset with Pandas
2. **Pre-processing** → Handle missing values, duplicates, derived columns
3. **EDA** → Univariate, bivariate, multivariate analysis
4. **Visualizations** → 10+ plots (line, bar, scatter, heatmap, etc.)
5. **Insights** → At least 5 key findings
6. **Report** → Summary of results & recommendations

---

## 📈 Key Insights
- Australia & New Zealand dominate export share.
- Machinery & textiles are top commodities by value.
- INR vs USD values show strong correlation.
- Minerals have high quantity but low value; machinery is the opposite.
- Seasonal peaks in Q2 indicate demand cycles.
