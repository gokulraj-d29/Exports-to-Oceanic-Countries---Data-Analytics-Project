# 🌏 Exports to Oceanic Countries - Data Analytics Project

## 📌 Overview
This repository contains a comprehensive **data analytics project** focused on India’s exports to Oceanic countries.  
The project demonstrates **end-to-end exploratory data analysis (EDA)** using Python — from data cleaning and transformation to visualization and insight generation.  

---

## 🎯 Objectives
- Perform **data cleaning & preprocessing** on trade data.
- Conduct **exploratory data analysis (EDA)** to uncover trade dynamics.
- Generate **10+ meaningful visualizations** using Matplotlib, Seaborn, and Plotly.
- Derive **5+ key insights** about export patterns, commodity trends, and currency impacts.
- Present findings in a **well-documented Jupyter Notebook** with Markdown explanations.

---

## 🛠 Tools & Technologies
- **Python (Anaconda Distribution)**  
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn, Plotly  
- **Jupyter Notebook / Google Colab**  
- **Excel/CSV Viewer** (for raw dataset inspection)  
- **GitHub** (for version control and project sharing)

## 🚀 Project Workflow
1. **Data Loading** → Import dataset with Pandas.  
2. **Pre-processing** → Handle missing values, duplicates, and create derived columns.  
3. **EDA** → Perform univariate, bivariate, and multivariate analysis.  
4. **Visualizations** → Create 10+ plots (line, bar, scatter, heatmap, etc.).  
5. **Insights** → Highlight at least 5 findings with clear explanations.  
6. **Report** → Summarize results and recommendations.  

---

## 📈 Key Insights
- Australia & New Zealand dominate export share.  
- Machinery & textiles are top commodities by value.  
- INR vs USD values show strong correlation, reflecting exchange rate impacts.  
- Minerals have high quantity but low value; machinery is the opposite.  
- Seasonal peaks in Q2 indicate demand cycles.
